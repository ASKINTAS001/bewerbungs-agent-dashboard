So baut der Agent eine Bewerbung – 6 Schritte:
  1. Passung wird bewertet
  2. Anschreiben wird geschrieben
  3. PDF wird erstellt
  4. Mappe wird zusammengestellt
  5. Upload zu Google Drive
  6. Fertig
Der Fortschritt kommt live aus der Tabelle build_status: jeder Schritt schreibt genau eine Zeile (Status-Nodes stehen auf „Execute Once"). Das Dashboard liest alle 2 Sekunden die neueste Zeile. Bei „Fertig“ verschwindet diese Anzeige und die Liste lädt neu.
